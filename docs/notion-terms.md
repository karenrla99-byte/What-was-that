# 바이브코딩 디자인 (노션 원본)

> 정은의 노션 페이지 「바이브코딩 디자인」을 옮긴 것. `docs/TERMS.md`에서 뜻 없이 이름만 적힌 용어는 여기 설명을 `meaning`으로 사용.
> 분류는 TERMS.md를 따르고, 이 문서의 분류는 참고만 하기 (예: 「UI용어/비교」 항목은 TERMS.md에서 각 분류로 옮겨짐).

웹앱을 만들 때 참고할 수 있도록 디자인 스타일과 UI 패턴을 용도별로 정리했습니다.

## 글자 스타일

- **애시드 그래픽 (Acid Graphics)**: 강렬한 색상과 실험적인 형태를 활용해 미래적이고 대담한 분위기를 만드는 스타일.
- **글리치 (Glitch)**: 글자가 깨지거나 어긋난 듯한 디지털 오류 효과. 사이버·실험적인 분위기에 어울림.
- **인플레이트 3D (Inflated 3D)**: 풍선처럼 부풀어 오른 입체 글자. 발랄하고 장난스러운 인상을 줌.
- **바우하우스 (Bauhaus)**: 원·삼각형·사각형 같은 기하학적 형태와 간결한 구성을 강조하는 스타일.
- **아르데코 (Art Deco)**: 대칭, 장식적인 선, 고급스러운 기하학 패턴을 활용하는 스타일.
- **아웃라인 (Outline)**: 글자의 면을 채우지 않고 윤곽선만 강조하는 표현.
- **모노스페이스 (Monospace)**: 모든 글자가 같은 폭을 차지하는 고정폭 글꼴. 코드나 기술적인 분위기에 잘 어울림.
- **핸드레터링 (Hand Lettering)**: 손으로 직접 쓴 듯한 글자 표현. 친근하고 개성 있는 분위기를 만듦.
- **미니멀 (Minimal)**: 단순한 서체와 넉넉한 여백으로 내용과 가독성에 집중하는 스타일.

## 날짜 고르는 UI

### 달력과 날짜 선택

- **인라인 달력 (Inline Calendar)**: 화면 안에 달력을 항상 펼쳐 두는 방식. 날짜 선택이 핵심 기능일 때 유용.
- **팝오버 달력 (Popover Calendar)**: 날짜 입력란을 누르면 작은 달력이 나타나는 방식. 화면 공간을 절약할 수 있음.
- **바텀시트 (Bottom Sheet)**: 모바일 화면 아래에서 선택 창이 올라오는 방식. 날짜나 시간을 고를 공간이 넉넉함.
- **월 그리드 (Month Grid)**: 여러 달을 격자로 보여 주고 원하는 월을 선택하는 방식.
- **휠 피커 (Wheel Picker)**: 연·월·일을 스크롤 휠로 돌려 선택하는 방식. 모바일에서 자주 사용됨.
- **직접 입력 (Manual Input)**: 사용자가 날짜를 텍스트로 입력하는 방식. 입력 형식과 오류 안내가 중요함.
- **캘린더 (Calendar)**: 일정이나 날짜를 달력 형태로 보여 주는 UI. 날짜 선택뿐 아니라 일정 확인에도 사용됨.
- **월 선택 (Month Picker)**: 특정 날짜 대신 연도와 월만 고르는 방식. 월별 조회나 통계에 적합함.

### 기간과 시간 선택

- **범위 달력 (Date Range Calendar)**: 달력에서 시작일과 종료일을 선택하고 그 사이를 강조하는 방식.
- **기간 선택 (Date Range Picker)**: 시작일과 종료일 또는 정해진 기간을 고르는 UI. 달력 외에도 입력란이나 목록을 사용할 수 있음.
- **체크인·체크아웃 (Check-in / Check-out)**: 숙박 시작일과 종료일을 고르는 기간 선택 UI. 숙박 일수와 선택 가능 여부를 함께 보여 주면 유용함.
- **시간 슬롯 (Time Slot)**: 선택 가능한 시간대를 버튼이나 목록으로 보여 주는 방식. 예약에 적합함.
- **반복 설정 (Recurrence Settings)**: 매일·매주·매월 등 일정이 반복되는 주기와 종료 조건을 고르는 방식.

### 빠른 선택

- **빠른 선택 (Quick Select)**: 오늘, 내일, 최근 7일 등 자주 쓰는 날짜나 기간을 한 번에 고르는 기능.
- **빠른 선택 칩 (Quick Select Chips)**: 빠른 선택 옵션을 작은 버튼 모양의 칩으로 보여 주는 방식.

## 권한 묻는 화면

### 요청하는 권한

- **알림 권한 (Notification Permission)**: 앱이 사용자에게 알림을 보낼 수 있도록 요청.
- **위치 권한 (Location Permission)**: 현재 위치를 사용하기 위해 요청. 위치 기반 검색이나 안내에 활용됨.
- **카메라 권한 (Camera Permission)**: 촬영이나 QR 코드 스캔처럼 카메라가 필요한 기능을 위해 요청.

### 요청 흐름과 상태

- **미리 안내 (Permission Pre-prompt)**: 시스템 권한 창을 띄우기 전에 왜 필요한지와 허용 시 이점을 설명.
- **시스템 모달 (System Permission Dialog)**: 운영체제나 브라우저가 표시하는 공식 권한 요청 창. 모양과 선택지는 환경에 따라 달라짐.
- **다시 묻기 (Permission Re-prompt)**: 권한이 필요한 상황에서 다시 요청을 유도. 실제 재요청 가능 여부는 운영체제·브라우저와 이전 선택에 따라 달라짐.
- **설정으로 보내기 (Open Settings)**: 시스템 창을 다시 띄울 수 없을 때 설정에서 권한을 변경하도록 안내.
- **일부만 허용 (Limited Access)**: 환경에서 지원하는 경우 제한된 범위의 접근을 허용한 상태. 허용된 범위와 사용할 수 있는 기능을 안내.
- **거절 뒤 화면 (Permission Denied Screen)**: 권한이 없어도 가능한 기능, 대체 방법, 다시 설정하는 방법을 안내.

## 검색 화면 구성 요소

- **검색창 (Search Bar)**: 검색어를 입력하고 검색을 시작하는 기본 요소.
- **자동완성 (Autocomplete)**: 입력 중인 내용에 맞춰 검색어 또는 결과 후보를 제안.
- **최근 검색어 (Recent Searches)**: 사용자가 이전에 검색한 단어를 보여 주어 재검색을 돕는 기능.
- **인기 검색어 (Trending Searches)**: 다른 사용자들이 많이 찾는 검색어를 보여 주는 영역.
- **필터 (Filter)**: 카테고리, 날짜, 가격 등 조건으로 검색 결과를 좁히는 기능.
- **정렬 (Sort)**: 관련도, 최신순, 가격순 등 결과를 보여 주는 순서를 바꾸는 기능.
- **검색어 강조 (Search Term Highlighting)**: 결과 안에서 검색어와 일치하는 부분을 눈에 띄게 표시.
- **결과 없음 (No Results)**: 일치하는 결과가 없을 때 표시하는 상태. 검색어 수정이나 필터 초기화 방법을 함께 안내하면 좋음.
- **검색 범위 탭 (Search Scope Tabs)**: 전체·상품·게시글처럼 검색할 대상이나 결과 유형을 나누는 탭.

## 텍스트 등장 효과

- **타이핑 (Typing Effect)**: 글자가 키보드로 입력되는 것처럼 한 글자씩 나타남.
- **페이드 업 (Fade Up)**: 텍스트가 아래에서 위로 이동하면서 서서히 나타남.
- **글자 순차 등장 (Staggered Character Animation)**: 글자마다 약간의 시간 차를 두고 차례로 나타남.
- **카운트 업 (Count Up)**: 숫자가 0이나 시작값에서 목표값까지 증가하며 나타남.
- **스크램블 (Scramble Text)**: 무작위 문자가 빠르게 바뀌다가 최종 문장으로 정리되는 효과.
- **마스크 리빌 (Mask Reveal)**: 가려진 영역 뒤에서 텍스트가 드러나는 효과.
- **하이라이트 (Highlight)**: 텍스트에 밑줄이나 배경색이 순서대로 칠해지며 강조됨.
- **단어 교체 (Word Swap)**: 문장 안의 특정 단어가 다른 단어로 바뀌는 효과.
- **블러 인 (Blur In)**: 흐릿한 텍스트가 점점 선명해지며 나타남.

## 화면 전환

- **푸시 (Push Transition)**: 새 화면이 기존 화면을 밀어내며 나타나는 전환.
- **모달 등장 (Modal Entrance)**: 현재 화면 위에 별도의 창이 나타나는 방식.
- **페이드 스루 (Fade Through)**: 기존 화면이 사라진 뒤 새 화면이 부드럽게 나타나는 전환.
- **공유 요소 (Shared Element)**: 두 화면에 공통으로 있는 요소가 위치나 크기를 바꾸며 이어지는 전환.
- **카드 확장 (Card Expansion)**: 목록의 카드가 커지며 상세 화면으로 연결되는 전환.
- **줌 (Zoom)**: 화면이나 요소가 확대·축소되며 바뀌는 전환.
- **순차 등장 (Staggered Entrance)**: 화면 요소가 시간차를 두고 차례로 나타나는 효과.
- **탭 전환 (Tab Transition)**: 선택한 탭에 맞게 콘텐츠가 바뀌는 방식.
- **시트 확장 (Sheet Expansion)**: 화면 아래의 시트가 위로 커지며 더 많은 내용을 보여 주는 방식.

## 화면 배치

- **히어로 (Hero)**: 화면 상단에 큰 이미지나 핵심 메시지를 강조하는 배치.
- **벤토 그리드 (Bento Grid)**: 크기가 서로 다른 카드들을 격자처럼 조합하는 배치.
- **스플릿 (Split Layout)**: 화면을 두 영역으로 나눠 서로 다른 내용을 보여 주는 배치.
- **카드 그리드 (Card Grid)**: 비슷한 형태의 카드들을 격자로 배열하는 방식.
- **사이드바 레이아웃 (Sidebar Layout)**: 화면 옆에 메뉴나 보조 정보를 고정해 두는 배치.
- **매거진 (Magazine Layout)**: 다양한 크기의 제목·이미지·본문을 편집물처럼 조합하는 배치.
- **대시보드 (Dashboard)**: 지표와 차트, 상태 정보를 한 화면에 모아 보여 주는 배치.
- **Z 패턴 (Z-Pattern)**: 시선이 Z자 형태로 이동하도록 핵심 요소를 배치하는 방식.
- **풀블리드 (Full Bleed)**: 이미지나 배경을 화면 가장자리까지 채우는 배치.

## 첫 화면과 시작 단계

앱을 처음 열거나 가입할 때 만나는 화면과 안내입니다.

- **스플래시 (Splash Screen)**: 앱을 여는 동안 로고나 브랜드를 잠시 보여 주는 화면.
- **온보딩 (Onboarding)**: 앱의 주요 기능이나 사용 방법을 처음 사용자에게 소개하는 과정.
- **권한 요청 (Permission Request)**: 알림·위치 등 기능 사용에 필요한 권한을 요청하는 단계.
- **코치마크 (Coach Mark)**: 특정 버튼이나 기능을 짚어 주며 사용법을 알려 주는 안내.
- **간편 로그인 (Social Login)**: 다른 계정 등을 이용해 로그인이나 가입을 간소화하는 방식.
- **약관 동의 (Terms and Conditions Consent)**: 서비스 이용에 필요한 약관을 확인하고 동의받는 단계.
- **프로필 설정 (Profile Setup)**: 이름, 사진 등 사용자 정보를 입력하는 단계.
- **스켈레톤 (Skeleton)**: 콘텐츠가 준비되는 동안 화면의 대략적인 형태를 보여 주는 임시 UI.
- **웰컴 화면 (Welcome Screen)**: 사용자를 환영하고 시작할 행동을 안내하는 화면.

## 버튼 상태

- **기본 (Default)**: 특별한 상호작용이 없는 일반적인 상태.
- **호버 (Hover)**: 마우스 포인터를 버튼 위에 올렸을 때의 상태.
- **눌림 (Pressed)**: 버튼을 누르고 있는 동안의 상태.
- **포커스 (Focus)**: 키보드 등으로 버튼에 초점이 맞춰진 상태.
- **비활성 (Disabled)**: 현재 누를 수 없는 상태. 이유나 필요한 조건을 알려 주면 좋음.
- **로딩 (Loading)**: 버튼을 누른 뒤 작업이 진행 중인 상태.
- **성공 (Success)**: 요청한 작업이 완료됐음을 보여 주는 상태.
- **오류 (Error)**: 작업이 실패했음을 보여 주고 재시도 등을 안내하는 상태.
- **선택됨 (Selected)**: 여러 옵션 중 해당 버튼이 선택되어 있음을 나타내는 상태.

## 레이아웃

- **그리드 레이아웃 (Grid Layout)**: 행과 열의 규칙에 맞춰 요소를 배치하는 방식.
- **벤토 레이아웃 (Bento Layout)**: 크기가 다른 영역을 조합해 중요한 내용을 강조하는 방식.
- **메이슨리 레이아웃 (Masonry Layout)**: 높이가 다른 요소를 빈 공간을 줄이며 쌓는 방식.
- **리스트 레이아웃 (List Layout)**: 항목을 한 줄씩 세로로 나열하는 방식.
- **스플릿 레이아웃 (Split Layout)**: 화면을 두 영역으로 나누는 방식.
- **사이드바 레이아웃 (Sidebar Layout)**: 주 콘텐츠 옆에 탐색 메뉴나 보조 영역을 두는 방식.
- **컬럼 레이아웃 (Column Layout)**: 콘텐츠를 여러 세로 열로 나누어 배치하는 방식.

## 디자인 스타일

- **컷페이퍼 (Cut Paper)**: 오려 붙인 종이처럼 겹친 형태와 그림자로 표현하는 스타일.
- **잉크 (Ink)**: 번짐, 붓질 등 잉크의 질감을 활용하는 스타일.
- **리소 인쇄 (Risograph Printing)**: 제한된 색상과 겹침, 인쇄 어긋남을 살린 인쇄물 느낌의 스타일.
- **스케치북 (Sketchbook)**: 손그림, 낙서, 종이 질감을 활용한 자유로운 스타일.
- **수학 (Mathematical Design)**: 숫자, 수식, 도형 등 수학적 요소를 시각적으로 활용하는 스타일.
- **픽셀 (Pixel Art)**: 작은 사각형 픽셀을 드러내 레트로 디지털 느낌을 주는 스타일.
- **아이소메트릭 (Isometric)**: 사물을 일정한 각도의 입체 시점으로 표현하는 스타일.
- **미니멀리즘 (Minimalism)**: 요소를 최소화하고 여백과 핵심 콘텐츠에 집중하는 스타일.
- **에디토리얼 (Editorial)**: 잡지처럼 타이포그래피와 이미지의 구성을 강조하는 스타일.
- **스위스 스타일 (Swiss Style)**: 명확한 그리드, 산세리프 서체, 정돈된 구성을 강조하는 스타일.
- **벤토 그리드 (Bento Grid)**: 크기가 다른 직사각형 영역을 조합해 정보를 보여 주는 스타일.
- **글래스모피즘 (Glassmorphism)**: 반투명 배경과 흐림 효과로 유리 같은 느낌을 주는 스타일.
- **클레이모피즘 (Claymorphism)**: 부드러운 입체감과 둥근 형태로 점토 같은 느낌을 주는 스타일.
- **네오 브루탈리즘 (Neobrutalism)**: 굵은 테두리와 강한 색, 의도적으로 투박한 구성을 활용하는 스타일.
- **맥시멀리즘 (Maximalism)**: 색상, 패턴, 장식을 풍부하게 활용하는 스타일.
- **키네틱 타이포그래피 (Kinetic Typography)**: 움직이는 글자로 메시지와 리듬을 강조하는 스타일.
- **그레이니 그라데이션 (Grainy Gradient)**: 색상 변화에 입자 질감을 더하는 스타일.
- **Y2K 크롬 (Y2K Chrome)**: 2000년대 초반 감성과 반짝이는 금속 질감을 결합한 스타일.
- **멤피스 (Memphis)**: 밝은 색상과 기하학적 패턴을 경쾌하게 조합하는 스타일.
- **바우하우스 (Bauhaus)**: 기하학적 형태와 기능 중심의 구성을 강조하는 스타일.
- **팝 아트 (Pop Art)**: 대중문화 이미지와 선명한 색상을 활용하는 스타일.
- **콜라주 (Collage)**: 사진, 종이, 그림 등 서로 다른 요소를 오려 붙인 듯 결합하는 스타일.
- **리소그래프 (Risograph)**: 리소 인쇄의 색상 겹침과 독특한 질감을 살린 표현.
- **아트 데코 (Art Deco)**: 대칭과 장식적인 기하학 패턴으로 화려함을 표현하는 스타일.
- **사이버펑크 (Cyberpunk)**: 네온, 어두운 배경, 미래 도시의 기술적 분위기를 활용하는 스타일.
- **아이소메트릭 (Isometric)**: 입체 공간을 일정한 각도로 보여 주는 표현. 위 항목과 같은 개념.
- **플랫 (Flat Design)**: 그림자나 입체 효과를 줄이고 단순한 형태와 색상으로 표현하는 스타일.
- **스큐어모피즘 (Skeuomorphism)**: 실제 사물의 형태와 질감을 디지털 화면에 재현하는 스타일.
- **뉴모피즘 (Neumorphism)**: 배경과 비슷한 색과 부드러운 그림자로 돌출·함몰 효과를 주는 스타일.
- **글래스모피즘 (Glassmorphism)**: 반투명 유리 같은 표현. 위 글래스모피즘과 같은 개념.
- **머티리얼 (Material Design)**: 구글의 머티리얼 디자인에 기반해 계층, 색상, 움직임을 체계적으로 사용하는 방식.
- **브루탈리즘 (Brutalism)**: 장식을 줄이고 거칠고 직설적인 구성을 드러내는 스타일.
- **다크 모드 (Dark Mode)**: 어두운 배경과 밝은 전경색을 사용하는 화면 테마.
- **리퀴드 글래스 (Liquid Glass)**: 유리처럼 투명하고 유동적으로 반응하는 시각적 표현.
- **미니멀 (Minimal)**: 단순한 구성으로 핵심 내용에 집중하는 표현. 미니멀리즘과 유사함.
- **Y2K (Y2K)**: 2000년대 초반의 디지털 감성과 미래적인 장식을 활용하는 스타일.

## 움직임

- **이즈 인 (Ease In)**: 느리게 시작해 점점 빨라지는 움직임.
- **이즈 아웃 (Ease Out)**: 빠르게 시작해 점점 느려지는 움직임.
- **스프링 (Spring)**: 용수철처럼 목표 지점을 향해 탄성 있게 움직이는 효과.
- **바운스 (Bounce)**: 공이 튀듯 목표 지점에서 통통 튀는 효과.
- **순차 등장 (Staggered Entrance)**: 여러 요소가 시간차를 두고 나타나는 효과.
- **페이드 (Fade)**: 투명도가 바뀌며 나타나거나 사라지는 효과.
- **슬라이드 (Slide)**: 요소가 한 방향에서 미끄러지듯 이동하는 효과.
- **확대 전환 (Zoom Transition)**: 요소나 화면이 커지며 바뀌는 효과.
- **공유 요소 전환 (Shared Element Transition)**: 같은 요소가 두 화면 사이에서 자연스럽게 이어지는 효과.

## 완료 표시

- **체크 그리기 (Checkmark Animation)**: 체크 표시가 그려지며 완료를 알리는 효과.
- **할 일 줄긋기 (Task Strikethrough)**: 완료한 항목에 취소선을 그어 상태를 표시.
- **버튼 모핑 (Button Morphing)**: 버튼이 체크 표시 등 다른 형태로 변하며 완료를 알림.
- **진행률 완료 (Progress Completion)**: 진행 바나 원형 표시가 끝까지 채워져 완료를 보여 줌.
- **보냄 애니메이션 (Send Animation)**: 메시지나 파일이 전송되는 모습을 움직임으로 표현.
- **스탬프 (Stamp)**: 도장을 찍는 듯한 표현으로 완료나 승인을 표시.
- **배지 획득 (Badge Award)**: 목표를 달성했을 때 배지를 보여 주는 방식.
- **컨페티 (Confetti)**: 색종이가 흩날리는 효과로 성취를 축하.
- **완료 화면 (Completion Screen)**: 작업 결과와 다음 행동을 별도 화면에서 안내.

## 로딩 패턴

- **스피너 (Spinner)**: 회전하는 표시로 작업이 진행 중임을 알림.
- **스켈레톤 (Skeleton)**: 실제 콘텐츠 대신 화면의 형태를 임시로 보여 줌.
- **진행 바 (Progress Bar)**: 작업의 진행 정도를 막대로 표시.
- **진행 링 (Progress Ring)**: 작업의 진행 정도를 원형으로 표시.
- **단계 표시 (Step Indicator)**: 작업이 여러 단계 중 어디까지 진행됐는지 표시.
- **블러 업 (Blur Up)**: 흐릿하거나 저해상도인 이미지를 먼저 보여 주고 선명하게 바꾸는 방식.
- **낙관적 UI (Optimistic UI)**: 서버 응답 전에 성공할 것으로 보고 화면을 먼저 갱신하는 방식. 실패 시 되돌리기와 안내가 필요함.
- **스트리밍 텍스트 (Streaming Text)**: 생성되거나 전달되는 텍스트를 받는 대로 표시.
- **로딩 버튼 (Loading Button)**: 버튼 안에 진행 표시를 넣어 요청 처리 중임을 알림.

## 알림·피드백

- **토스트 (Toast)**: 짧은 메시지가 잠시 나타났다가 사라지는 알림.
- **스낵바 (Snackbar)**: 짧은 메시지와 함께 실행 취소 같은 행동을 제공할 수 있는 알림.
- **배너 (Banner)**: 화면의 위나 아래에 표시되는 지속적인 안내 영역.
- **모달 (Modal)**: 현재 화면 위에 나타나 사용자의 확인이나 행동을 요청하는 창.
- **바텀시트 (Bottom Sheet)**: 화면 아래에서 올라와 선택지나 추가 내용을 보여 주는 영역.
- **인라인 오류 (Inline Error)**: 문제가 발생한 입력란이나 콘텐츠 가까이에 표시하는 오류 안내.
- **툴팁 (Tooltip)**: 특정 요소에 대한 짧은 설명을 가까이에 보여 주는 안내.
- **코치마크 (Coach Mark)**: 기능의 위치와 사용법을 강조해 알려 주는 안내.
- **배지 (Badge)**: 숫자나 점 등으로 새 소식, 개수, 상태를 표시하는 작은 요소.

## 입력 폼

- **텍스트 필드 상태 (Text Field States)**: 입력란의 기본, 포커스, 오류, 비활성 등 상태를 표현.
- **셀렉트 (Select)**: 목록에서 하나 이상의 옵션을 선택하는 입력 요소.
- **세그먼트 (Segmented Control)**: 서로 연결된 옵션을 나란히 보여 주고 하나를 고르는 요소.
- **스위치 (Switch)**: 설정을 켜거나 끄는 요소.
- **체크박스 (Checkbox)**: 항목의 선택 여부를 표시하며 여러 항목을 함께 고를 수 있는 요소.
- **라디오 (Radio Button)**: 여러 옵션 중 하나를 고르는 요소.
- **슬라이더 (Slider)**: 손잡이를 움직여 범위 안의 값을 고르는 요소.
- **수량 스테퍼 (Quantity Stepper)**: 더하기·빼기 버튼으로 수량을 조절하는 요소.
- **날짜 선택 (Date Picker)**: 달력이나 입력란 등으로 날짜를 고르는 요소.

## 제스처

- **탭 (Tap)**: 화면을 한 번 터치해 선택하거나 실행.
- **길게 누르기 (Long Press)**: 일정 시간 누르고 있어 추가 행동이나 메뉴를 실행.
- **스와이프 (Swipe)**: 화면을 한 방향으로 밀어 이동하거나 행동을 실행.
- **밀어서 삭제 (Swipe to Delete)**: 항목을 밀어 삭제 버튼을 드러내거나 삭제를 실행.
- **드래그 (Drag)**: 요소를 누른 채 끌어 위치를 옮기는 동작.
- **핀치 (Pinch)**: 두 손가락을 오므리거나 펼쳐 확대·축소하는 동작.
- **두 번 탭 (Double Tap)**: 화면을 빠르게 두 번 터치해 확대 등 특정 행동을 실행.
- **당겨서 새로고침 (Pull to Refresh)**: 화면을 아래로 당겨 콘텐츠를 다시 불러오는 동작.
- **가장자리 스와이프 (Edge Swipe)**: 화면 가장자리에서 밀어 뒤로 가기나 메뉴 열기 등을 실행.

## 메뉴 버튼 모양

- **햄버거 (Hamburger Menu)**: 가로줄 세 개로 표시하는 메뉴 아이콘.
- **케밥 (Kebab Menu)**: 세로 점 세 개로 표시하는 추가 메뉴 아이콘.
- **미트볼 (Meatballs Menu)**: 가로 점 세 개로 표시하는 추가 메뉴 아이콘.
- **와플 (Waffle Menu)**: 여러 개의 점이나 사각형을 격자로 배열한 아이콘.
- **벤토 (Bento Menu)**: 여러 개의 사각형을 격자로 배열한 메뉴 아이콘.
- **도너 (Doner Menu)**: 길이가 다른 가로줄을 겹쳐 놓은 아이콘. 필터나 정렬에 쓰이기도 함.
- **베지 버거 (Veggie Burger Menu)**: 길이가 서로 다른 가로줄로 만든 변형 메뉴 아이콘.
- **계단 (Staircase Menu)**: 길이나 위치가 단계적으로 달라지는 줄을 사용한 아이콘.
- **슬라이드 (Sliders Icon)**: 조절 손잡이 모양을 사용한 아이콘. 필터나 설정에 자주 쓰임.

## 빈 화면

- **첫 사용 (First-use Empty State)**: 아직 콘텐츠가 없는 사용자에게 첫 행동을 안내.
- **검색 결과 없음 (No Search Results)**: 검색어에 맞는 결과가 없을 때 수정이나 재검색을 안내.
- **필터 결과 없음 (No Filter Results)**: 선택한 조건에 맞는 결과가 없을 때 필터 변경을 안내.
- **오프라인 (Offline)**: 인터넷 연결이 없을 때 가능한 기능과 재연결 방법을 안내.
- **권한 필요 (Permission Required)**: 필요한 권한과 허용 방법, 대체 수단을 안내.
- **모두 완료 (All Done)**: 처리할 항목이 없음을 알리고 완료 상태를 보여 줌.
- **삭제 직후 (Post-deletion Empty State)**: 삭제 후 남은 항목이 없을 때 상태와 가능한 다음 행동을 안내.
- **오류 화면 (Error Screen)**: 콘텐츠를 불러오지 못한 이유와 재시도 방법을 안내.
- **잠김 (Locked)**: 접근할 수 없는 이유와 잠금을 해제할 방법을 안내.

## 평점 UI

- **별점 (Star Rating)**: 별의 개수로 평가 점수를 선택하거나 표시.
- **반 별점 (Half-star Rating)**: 별의 절반 단위까지 세분화해 점수를 표현.
- **NPS 점수 (Net Promoter Score (NPS))**: 추천 의향을 보통 0~10점으로 묻는 평가 방식.
- **이모지 평가 (Emoji Rating)**: 표정이나 그림으로 만족도를 직관적으로 선택.
- **좋아요·싫어요 (Thumbs Up / Thumbs Down)**: 두 가지 반응으로 간단하게 평가.
- **평점 슬라이더 (Rating Slider)**: 손잡이를 움직여 점수를 선택.
- **평점 요약 (Rating Summary)**: 평균 점수와 평가 수, 점수별 분포 등을 보여 줌.
- **평가 태그 (Review Tags)**: '친절해요'처럼 평가 이유를 짧은 선택지로 제공.
- **평점 배지 (Rating Badge)**: 점수나 평가 상태를 작은 배지로 표시.

- **스크롤 진행 바 (Scroll Progress Bar)**: 전체 콘텐츠 중 얼마나 스크롤했는지 표시.

## UI용어/비교

- **프로그레스 바 서큘러 (Circular Progress Bar)**: 작업의 진행 정도를 원형으로 표시하는 UI. 원형 진행률과 같은 개념.
- **아바타 그룹 (Avatar Group)**: 여러 사용자의 프로필 이미지를 나란히 또는 겹쳐 보여 주는 요소.
- **피커 (Picker)**: 날짜, 시간, 색상 등 정해진 값 중 하나를 고르는 선택 UI.
- **플레이스홀더 (Placeholder)**: 입력 전 텍스트 필드에 표시되는 예시나 안내 문구. 입력 라벨을 대신하지 않는 것이 좋음.
- **디폴트 vs 레스팅 (Default vs. Resting)**: 디폴트는 기본값이나 기본 설정을, 레스팅은 포커스·호버 등 상호작용이 없는 평상시 상태를 뜻함.
- **토글 vs 체크박스 (Toggle vs. Checkbox)**: 토글은 보통 설정의 켜짐·꺼짐을 즉시 적용하고, 체크박스는 하나 이상의 항목 선택에 자주 사용함.
- **라디오 vs 체크박스 (Radio Button vs. Checkbox)**: 라디오는 같은 그룹에서 하나만 선택하고, 체크박스는 여러 항목을 함께 선택할 수 있음.
- **탭 vs 세그먼트 (Tabs vs. Segmented Control)**: 탭은 주로 콘텐츠 영역을 나누고, 세그먼트는 연관된 소수의 옵션이나 보기를 전환함.
- **모달 vs 바텀시트 (Modal vs. Bottom Sheet)**: 모달은 화면 위에 대화상자를 띄우고, 바텀시트는 화면 아래에서 올라와 내용이나 선택지를 보여 줌.
- **토스트 vs 스낵바 (Toast vs. Snackbar)**: 둘 다 짧은 알림이지만, 스낵바는 실행 취소 등 행동을 함께 제공하는 경우가 많음.
- **툴팁 vs 팝오버 (Tooltip vs. Popover)**: 툴팁은 짧은 설명에, 팝오버는 더 다양한 정보나 상호작용을 담는 데 사용함.
- **칩 vs 배지 (Chip vs. Badge)**: 칩은 선택·필터·입력 같은 상호작용에, 배지는 상태나 개수 표시에 주로 사용함.
- **스피너 vs 스켈레톤 (Spinner vs. Skeleton)**: 스피너는 진행 중임을 간단히 알리고, 스켈레톤은 불러올 콘텐츠의 형태를 미리 보여 줌.
- **스테퍼 vs 슬라이더 (Stepper vs. Slider)**: 스테퍼는 버튼으로 값을 일정 단위씩 바꾸고, 슬라이더는 범위 안에서 손잡이를 움직여 값을 고름.
