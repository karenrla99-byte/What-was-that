## 1. 이름과 한 줄 소개
- **제목:** 그거 뭐더라?
- **부제:** 바이브코딩 용어사전 · *Vibe Glossary*
- **소개:** "이거 뭐라고 부르지?"를 해결하는 움직이는 그림 사전. 바이브코딩할 때 원하는 디자인·UI를 **정확한 이름으로 프롬프트에 쓰기 위한 사이트.**

## 2. 쓰임
- 머릿속 화면을 AI에게 설명할 때 "그 아래서 올라오는 창" 대신 **"바텀시트"**라고 정확히 쓰기
- 비슷한 것 중 무엇을 원하는지 고르기 (토스트 vs 스낵바)
- 상세 화면의 **요청 문장을 복사**해서 바로 프롬프트에 붙여 넣기
- 바이브코딩 초보가 자주 만나는 말과 문제를 미리 알기 (🌱 처음 시작)
- 연수에서는 화면에 띄워 함께 보는 설명 자료로 활용

## 3. 화면 구성

### 3-1. 홈
```
┌──────────┬────────────────────────────────────┬──┐
│ 그거       │      [ 🔍 검색 (한글·영어·초성) ]     │  │
```

- **전체화면·설정 버튼 없음** (설명 사이트라서)
- 검색창은 스크롤해도 위에 고정
- 브라우저 탭 제목: `그거 뭐더라? · Vibe Glossary`

### 3-2. 왼쪽 사이드바 = 카테고리 선택
- 맨 위에 제목·부제, 그 아래 **전체** + 큰 묶음 11개 (아이콘 + 이름)
- 큰 묶음을 누르면 **그 묶음 카드만** 보이고, 사이드바에서 그 묶음이 펼쳐져 작은 분류가 보임
  - 예: 🧩 부품 → 입력 폼 · 버튼 · 메뉴 버튼 모양 · 이동 부품 · 콘텐츠 담기 · 미디어 · 데이터 보여주기 · 인디케이터 · 평점 UI · 날짜 고르는 UI · 검색 화면
- 작은 분류를 누르면 그 위치로 부드럽게 스크롤
- 스크롤하면 지금 보고 있는 작은 분류가 루미너스 블루로 켜짐
- 묶음 안에서는 작은 분류별로 묶어 보여 줌. 단 **🛠 만들고 배포하기 · 💬 AI와 일하기**는 개념 용어라 분류 안에서 ㄱㄴㄷ순
- 좁은 화면(휴대폰)에서는 왼쪽 위 햄버거 버튼 → 사이드바가 드로어로 나옴

### 3-3. 오른쪽 색인 = '전체'에서만
- 왼쪽에서 **전체**를 골랐을 때만 오른쪽에 얇은 색인 띠가 나타남
- 전체는 모든 용어를 **ㄱㄴㄷ순**으로 한 번에 보여 줌 (사전처럼)
- 색인 띠: **ㄱ ㄴ ㄷ ㄹ ㅁ ㅂ ㅅ ㅇ ㅈ ㅊ ㅋ ㅌ ㅍ ㅎ A** (A = 영어·숫자로 시작하는 용어)
- 누르면 그 글자로 바로 이동, 스크롤하면 지금 위치 글자가 켜짐
- 해당 글자로 시작하는 용어가 없으면 흐리게
- 다른 묶음을 고르면 색인 띠는 사라짐

### 3-4. 검색
- 한글, 영어, **초성**("ㅂㅌㅅㅌ" → 바텀시트) 모두 검색
- 설명 안의 낱말도 찾음 ("아래서 올라오는" → 바텀시트, 시트 확장)
- 결과 안에서 검색어 강조, 결과가 없으면 비슷한 이름 추천
- 어느 묶음에 있든 전체 용어에서 찾음
- 검색창 안내 문구: `그거… 뭐였더라? (예: 아래서 올라오는 창)`

### 3-5. 카드 (1:1, 이름 + 애니메이션만)
```
┌──────────────┐
│          [vs]│  ← 헷갈리는 짝 있을 때만, 오른쪽 위 작게
│ [애니메이션]  │  ← 위 약 75%, 2~3초 반복
│              │
├──────────────┤
│ 바텀시트      │  ← 아래 약 25%
│ Bottom Sheet │     한글 이름(굵게) + 영어 이름(작게, 기울임)
└──────────────┘
```
- **비율 1:1 정사각형**
- 카드에는 **이름과 애니메이션만**. 한 줄 설명·분류 태그·복사 버튼은 상세 화면에만
- 이름이 길면 두 줄까지, 넘치면 말줄임(…)
- 화면에 보이는 카드만 애니메이션 재생 (느려지지 않게)
- 마우스를 올리면 카드가 살짝 떠오르고 테두리가 루미너스 블루로

**한 줄 카드 수**
| 화면 | 한 줄 카드 수 | 카드 크기 (대략) |
|---|---|---|
| 큰 모니터 (1680px 이상) | 5개 | 250px |
| **데스크탑 (1280~1680px)** | **4개** | 250px |
| 노트북·태블릿 가로 (1024px 안팎) | 3개 | 230px |
| 태블릿 세로 | 2개 | 300px |
| 휴대폰 | 2개 | 165px |

- 카드 사이 간격 16px (휴대폰 12px)

### 3-6. 상세 화면
카드가 커지며 열림 (**카드 확장** 전환)
```
[← 닫기]                         [‹ 이전] [다음 ›]
바텀시트                          🧩 부품 · 알림·피드백
Bottom Sheet
┌──────────────────────────────┐
│     크게 움직이는 예시         │  [▶ 다시 보기] [✋ 직접 해보기]
└──────────────────────────────┘
뜻   화면 아래에서 올라와 선택지나 추가 내용을 보여 주는 영역.

💬 프롬프트에 이렇게 쓰세요                       [📋 복사]
   "설정 버튼을 누르면 화면 아래에서 바텀시트가 올라와서
    글자 크기를 고를 수 있게 해줘"

🔑 같이 쓰면 좋은 말   오버레이 · 시트 확장 · 스와이프로 닫기
⚖️ 헷갈리는 짝         모달 vs 바텀시트  → 나란히 비교 보기
```
- **프롬프트 문장이 이 사이트의 핵심**이라 뜻 바로 아래, 크게 배치
- 📋 복사를 누르면 "복사됐어요" 토스트
- 프롬프트 문장은 "언제 + 어디서 + 무엇이 + 어떻게" 구조로 통일
- **같이 쓰면 좋은 말**: 함께 쓰면 더 정확해지는 용어
- **헷갈리는 짝**: 두 개를 나란히 동시에 재생, 아래에 "이럴 땐 이것" 한 줄씩

### 3-7. 처음이라면 이것부터
전체 화면 맨 위에 추천 카드 10~12장 가로 줄 (옆으로 넘겨 보기). 끝에 "🌱 처음 시작 모두 보기" 바로가기:
바이브코딩 · 프롬프트 · 코드 블록 · 컴포넌트 · 반응형 · 모달 · 토스트 · 바텀시트 · 배포 · 에러 메시지 · 콘솔 · 되돌리기

### 겹치는 용어 처리 (카드 하나 + 태그 여러 개)
전체(ㄱㄴㄷ순)에서는 한 번만 보이고, 각 묶음에서는 해당 분류마다 보임.

| 용어 | 나오는 분류 | 처리 |
|---|---|---|
| 글래스모피즘 / 아이소메트릭 | 노션 디자인 스타일 안에 2번씩 | 1개로 합침 |
| 리소 인쇄 · 리소그래프 | 디자인 스타일 | 1개 (다른 이름에 둘 다) |
| 미니멀 · 미니멀리즘 | 글자 스타일, 디자인 스타일 | 글자 쪽 '미니멀'은 따로, 디자인 스타일은 '미니멀리즘' 1개 |
| Y2K · Y2K 크롬 | 디자인 스타일 | 따로 두고 서로 '같이 쓰면 좋은 말'로 연결 |
| 바우하우스 · 아르데코(아트 데코) | 글자 스타일, 디자인 스타일 | 글자용·화면용 예시가 달라서 따로 |
| 벤토 그리드 / 벤토 레이아웃 | 화면 배치, 디자인 스타일 | 1개 + 태그 2개 (메뉴 버튼 '벤토'는 별개) |
| 스플릿 · 사이드바 레이아웃 | 화면 배치 (노션 화면 배치+레이아웃) | 1개씩 |
| 스켈레톤 | 첫 화면, 로딩 패턴 | 1개 + 태그 2개 |
| 진행 바 = 프로그레스 바 | 로딩, 인디케이터 | 1개 + 다른 이름 |
| 진행 링 = 원형 진행률 = 프로그레스 바 서큘러 | 로딩, 인디케이터 | 1개 + 다른 이름 |
| 단계 표시 = 스텝 인디케이터 | 로딩, 인디케이터 | 1개 |
| 순차 등장 | 화면 전환, 움직임 | 1개 |
| 공유 요소 = 공유 요소 전환 / 줌 = 확대 전환 | 화면 전환, 움직임 | 1개씩 |
| 바텀시트 | 날짜 UI, 알림·피드백 | 1개 + 태그 2개 |
| 코치마크 | 첫 화면, 알림·피드백 | 1개 + 태그 2개 |
| 권한 요청 | 첫 화면 (권한 묻는 화면과 연결) | 1개 |
| 검색 결과 없음 = 결과 없음 | 검색 화면, 빈 화면 | 1개 + 태그 2개 |
| 날짜 선택 · 캘린더 · 기간 선택 | 입력 폼, 날짜 UI | 1개씩 + 태그 2개 |
| 키보드 단축키 · 자주 쓰는 단축키 | 손동작, 처음 시작 | 따로 두고 연결 |

## 6. 카드 애니메이션 원칙
- **이미지·영상 없이 코드(HTML·CSS·SVG)로** 그림 → 가볍고 선명
- **카드용**: 2~3초 짧게 반복. 핵심 동작 하나만 (바텀시트 = 올라왔다 내려감)
- **상세용**: 같은 애니메이션을 크게 + 다시 보기, 직접 해보기
- 색은 **루미너스 블루 + 회색**으로 통일
- 기기에서 '동작 줄이기'를 켜 둔 사람에게는 자동으로 멈춘 첫 장면만 보여 줌

| 묶음 | 카드 애니메이션 방식 |
|---|---|
| 🌱 처음 시작 | 작은 브라우저·코드 창 안에서 상황이 벌어짐 (괄호 짝: 닫는 괄호가 빠지면 화면이 하얘짐 → 넣으면 다시 나타남) |
| 🎨 생김새 | 같은 "메모 아이콘 + 짧은 글"을 스타일만 바꿔 보여 줌. 꾸밈 속성은 값이 0→최대로 바뀜 (모서리 둥글기: 네모→알약) |
| 🧩 부품 | 작은 화면 안에서 부품이 실제로 작동 (프로그레스 바 차오름, 별점 채워짐) |
| 🎬 움직임 | 같은 네모 상자가 효과별로 움직임 (이즈 인·이즈 아웃은 두 상자가 나란히 경주) |
| 📱 상황별 화면 | 작은 폰 화면 안에 해당 화면이 등장 |
| ✋ 손동작 | 손가락 동그라미가 누르거나 밀고 결과가 바뀜 |
| 🎮 학습·게임 UI | 카드가 끌려가 맞는 칸에 들어가고 정답 표시 |
| 🧠 UX 원칙 | 왼쪽 아쉬운 예 → 오른쪽 좋은 예로 바뀜 |
| 📐 화면 크기 | 화면 틀이 넓어졌다 좁아지며 배치가 바뀜 |
| 🛠 만들고 배포하기 | 작은 흐름도 (배포: 내 컴퓨터 → GitHub → 인터넷 주소로 파일이 날아감) |
| 💬 AI와 일하기 | 말풍선 흐름 (작게 나눠 요청: 큰 덩어리가 작은 조각으로 쪼개져 차례로 완성) |

- 카드 안 애니메이션 칸: 카드보다 한 단계 더 불투명한 흰 바탕
- 모서리: 카드 20px, 상세 화면 32px, 검색창·메뉴 선택 표시는 알약 모양

- 선택된 메뉴: 유리 판 안에 연한 파랑 알약 + 파랑 글자
- 글자 바로 뒤는 거의 불투명하게 (프로젝터에서도 읽히게)
