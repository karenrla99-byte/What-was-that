# 자세한 설명 초안

> `용어 이름 | 자세한 설명` 한 줄씩. `npm run build:terms`가 읽어서 terms.json의 `more`에 넣어요. 상세 화면의 [자세히 보기]를 누르면 펼쳐져요.
> 규칙: 기본 설명(쉬운 뜻)보다 한 걸음 더. 쉬운 말 · 3~4문장 · 끝말 "~예요/~해요" · 왜 필요한지, 언제 만나는지, 비유나 예시 하나
> 문장 사이를 ` // `로 나누면 줄을 바꿔서 보여 줘요.
> 모두 Claude가 쓴 초안이에요. 고치고 싶으면 이 파일에서 문장만 바꾸면 돼요.

## 기본 말
바이브코딩 | 코드를 한 줄도 몰라도, 만들고 싶은 것을 말로 설명하면 AI가 코드를 대신 써 줘요. // 나는 "무엇을, 어떻게" 설명하고, 결과를 눌러 보며 "여기를 이렇게 바꿔 줘" 하고 고쳐 나가요. // 요리사에게 주문하는 손님 같아요. 요리법은 몰라도 원하는 맛을 정확히 말하면 돼요. 그래서 이 사전처럼 정확한 이름을 아는 게 중요해요.
코드 | 컴퓨터는 사람 말을 바로 못 알아들어서, 정해진 규칙으로 쓴 글이 필요해요. 그게 코드예요. // 레시피에 "물 500ml를 끓인다"처럼 순서가 적혀 있듯, 코드에는 "버튼을 누르면 점수를 1 올린다"처럼 할 일이 적혀 있어요. // 바이브코딩에서는 AI가 코드를 써 주니까, 나는 코드를 읽을 줄 몰라도 괜찮아요.
실행 | 코드는 써 두기만 하면 그냥 글자예요. 실행해야 비로소 화면이 뜨고 버튼이 눌려요. // 레시피를 읽는 것과 실제로 요리하는 것의 차이예요. // AI 도구에서는 보통 결과물 창이 자동으로 실행해 줘요. 직접 할 때는 파일을 브라우저로 열거나 터미널에서 실행 명령을 써요.
미리보기 | 만든 것을 다른 사람에게 보여 주기 전에 나만 먼저 확인하는 화면이에요. // 학습지를 인쇄하기 전에 '인쇄 미리보기'로 한 번 보는 것과 같아요. // 여기서 버튼을 눌러 보고, 이상한 곳을 찾아 AI에게 고쳐 달라고 해요.
웹사이트 | 주소를 치고 들어가서 주로 글과 그림을 '읽는' 곳이에요. // 학교 홈페이지, 블로그, 소개 페이지가 대표적이에요. // 누르고 입력하며 무언가를 '하는' 곳은 웹앱이라고 따로 불러요. 둘의 경계는 흐릿하지만, 프롬프트를 쓸 때 구분하면 AI가 더 잘 알아들어요.
웹앱 | 브라우저에서 열리지만, 앱처럼 누르고 입력하고 저장하는 일을 하는 페이지예요. // 퀴즈, 출석 체크, 모둠 뽑기, 타이머처럼 '쓰는' 것이면 웹앱이에요. // 따로 설치하지 않아도 주소만 있으면 휴대폰, 태블릿, 컴퓨터 어디서나 열려서 수업에 쓰기 좋아요.
노코드 | 코드 대신 블록을 끌어다 놓거나 칸을 채워서 만드는 도구예요. // 패들렛, 구글 사이트, 노션이 그 예예요. 쉽고 빠르지만 도구가 허락한 만큼만 바꿀 수 있어요. // 바이브코딩은 AI가 진짜 코드를 써 주니까, 노코드보다 더 자유롭게 원하는 모양을 만들 수 있어요.
템플릿 | 이미 만들어 둔 틀이에요. 내용만 바꿔 넣으면 금방 완성돼요. // 학습지 양식, 가정통신문 서식처럼 모양과 칸은 정해져 있고 글만 바꾸는 거예요. // AI에게 "이 퀴즈를 템플릿으로 만들어서 문제만 바꿔 쓸 수 있게 해 줘"라고 하면 다음 수업에도 다시 쓸 수 있어요.
결과물 창 | AI와 대화하는 칸 옆에 만든 화면이 바로 뜨는 칸이에요. // 코드를 따로 복사하지 않아도 여기서 바로 눌러 보고 확인할 수 있어요. // 이상한 곳을 찾으면 그 모습을 그대로 설명하거나 캡처해서 AI에게 보여 주면 돼요.
버전 | 고칠 때마다 쌓이는 '몇 번째 판'이에요. v1, v2, v3처럼 불러요. // 학습지를 고칠 때 "최종", "진짜최종"으로 파일이 늘어나는 것과 비슷해요. // 잘 되는 버전을 기억해 두면, 고치다 망가졌을 때 "v3으로 돌아가 줘"라고 할 수 있어요.
무료 한도 | 돈을 내지 않고 쓸 수 있는 정해진 양이에요. 하루 대화 수, 저장 용량, 방문자 수 같은 거예요. // 한도를 넘으면 잠시 멈추거나, 다음 날까지 기다리거나, 요금이 생겨요. // 수업 시간에 갑자기 멈추지 않게, 쓰는 도구의 무료 한도를 미리 확인해 두면 좋아요.

## 컴퓨터와 브라우저
브라우저 | 인터넷 페이지를 열어 보여 주는 프로그램이에요. 크롬, 엣지, 사파리, 웨일이 있어요. // 같은 페이지도 브라우저마다 아주 조금씩 다르게 보일 수 있어요. // 만든 웹앱이 이상하면 "크롬에서는 되는데 사파리에서는 안 돼요"처럼 어느 브라우저인지 함께 말해 주면 좋아요.
주소 | 인터넷 페이지마다 하나씩 있는 집 주소예요. 화면 맨 위 주소창에 보여요. // https://로 시작하고, 이 주소를 알려 주면 누구나 같은 페이지에 찾아올 수 있어요. // 학생들에게 나눠 줄 때는 주소를 QR 코드로 바꾸면 편해요.
새 탭 / 새 창 | 지금 보던 페이지는 그대로 두고, 다른 페이지를 하나 더 여는 거예요. // 탭은 한 창 안에 책갈피처럼 나란히 생기고, 창은 아예 따로 떠요. // 링크를 눌렀을 때 학생들이 원래 화면을 잃지 않게 하려면 "새 탭으로 열리게 해 줘"라고 하면 돼요.
시크릿 창 | 방문 기록, 로그인, 저장된 파일 없이 '처음 온 사람'처럼 여는 창이에요. // 고쳤는데 화면이 그대로일 때, 시크릿 창으로 열어 보면 예전 파일(캐시) 때문인지 바로 알 수 있어요. // 학생 입장에서 처음 들어왔을 때 어떻게 보이는지 확인할 때도 좋아요.
쿠키 | 사이트가 내 브라우저에 남겨 두는 작은 메모예요. // "이 사람은 로그인했음", "글자 크기는 크게" 같은 걸 기억해서 다음에 와도 그대로 보여 줘요. // 쿠키를 지우면 로그인이 풀리고 설정이 처음으로 돌아가요.
팝업 차단 | 페이지가 멋대로 새 창을 띄우지 못하게 브라우저가 막는 기능이에요. // 광고 창을 막아 주는 고마운 기능이지만, 내가 만든 앱의 새 창도 막힐 수 있어요. // "아무 반응이 없어요"일 때 주소창 오른쪽에 차단 표시가 있는지 확인해 봐요.
다운로드 / 업로드 | 인터넷에 있는 걸 내 컴퓨터로 받아 오는 게 다운로드, 내 컴퓨터에 있는 걸 인터넷으로 올리는 게 업로드예요. // 학습지 파일을 받는 건 다운로드, 과제 사진을 제출하는 건 업로드예요. // 앱에서 "사진을 올릴 수 있게 해 줘"라고 하면 업로드 기능을 만들어 달라는 뜻이에요.
압축 파일 | 여러 파일을 봉투 하나에 담아 묶은 파일이에요. 이름 끝이 .zip이에요. // 파일이 많을 때 한 번에 주고받기 편하고, 크기도 조금 줄어요. // 열어서 쓰려면 먼저 "압축 풀기"를 해야 해요. 압축 안에서 바로 열면 제대로 안 될 때가 많아요.
확대·축소 | Ctrl을 누른 채 마우스 휠을 돌리면 화면 전체가 커지고 작아져요. Ctrl+0을 누르면 원래대로 돌아와요. // 프로젝터로 보여 줄 때 글자를 키우기 좋아요. // 화면이 이상하게 크거나 작아 보이면, 실수로 확대·축소가 된 건 아닌지 먼저 확인해 봐요.
자주 쓰는 단축키 | 키 두 개를 함께 눌러 빠르게 하는 일이에요. // 복사 Ctrl+C, 붙여 넣기 Ctrl+V, 되돌리기 Ctrl+Z, 전체 선택 Ctrl+A, 저장 Ctrl+S, 강력 새로고침 Ctrl+Shift+R. // 바이브코딩에서는 "전체 선택 → 복사 → 붙여 넣기"를 아주 많이 써서, 이것만 알아도 훨씬 빨라져요.
캡처 | 지금 보이는 화면을 사진처럼 찍는 거예요. 윈도우는 Win+Shift+S, 맥은 Cmd+Shift+4예요. // 화면이 이상할 때 말로 설명하기보다 캡처해서 AI에게 보여 주면 훨씬 정확하게 고쳐 줘요. // "이 부분이 이렇게 보여요"라고 한 줄 덧붙이면 더 좋아요.

## AI 답변 읽기
코드 블록 | AI 답변 속에 회색이나 검은 상자로 따로 묶인 부분이에요. 그 안에 든 게 진짜 코드예요. // 상자 밖의 글은 설명이고, 상자 안의 글만 파일에 넣어요. // 상자 오른쪽 위의 복사 버튼을 누르면 한 글자도 빠짐없이 복사돼요.
통째로 복사 | 코드를 마우스로 드래그해서 고르면 처음이나 끝이 빠지기 쉬워요. // 코드 상자 오른쪽 위 복사 버튼을 누르면 전부 정확하게 복사돼요. // 괄호 하나만 빠져도 전체가 안 움직이니까, 코드는 늘 통째로 복사해서 통째로 바꿔 넣어요.
마크다운 | 글 앞에 # 를 붙이면 제목, **글**은 굵게, - 를 붙이면 목록이 되는 간단한 글쓰기 방법이에요. // AI 답변도 이 방법으로 써서 제목과 목록이 예쁘게 보여요. // README 파일이나 노션에서도 쓰여서, 알아 두면 기획서를 정리할 때도 편해요.
줄 번호 | 코드 왼쪽에 1, 2, 3 하고 붙은 숫자예요. 코드의 일부가 아니라 위치를 알려 주는 표시예요. // 에러 메시지에 "42번째 줄"이라고 나오면 이 번호로 찾아가요. // AI에게 "30번째 줄 버튼 색을 바꿔 줘"처럼 짚어 말하면 더 정확해요.
들여쓰기 | 줄 앞에 넣은 빈칸이에요. 어떤 코드가 어떤 코드 '안에' 들어 있는지 보여 줘요. // 목차에서 하위 항목을 안쪽으로 들여 쓰는 것과 같아요. // 복사하다가 들여쓰기가 흐트러지면 읽기 어려워지고, 어떤 언어(파이썬)에서는 아예 오류가 나요.
괄호 짝 | ( ), { }, [ ]는 여는 것과 닫는 것이 꼭 짝을 이뤄야 해요. // 문장의 따옴표를 열고 안 닫으면 어디까지가 인용인지 모르는 것처럼, 하나만 빠져도 컴퓨터가 어디까지인지 몰라서 전체가 멈춰요. // 코드 일부만 고쳐 넣다가 자주 생기니, 고친 부분을 통째로 바꿔 넣는 게 안전해요.
따옴표 | 코드에서 글자는 곧은 따옴표(" " 또는 ' ') 안에 넣어요. // 한글 문서나 메신저에서 복사하면 둥근 따옴표(“ ”)로 바뀌어 섞이는데, 컴퓨터는 이걸 다른 글자로 봐서 오류가 나요. // 코드는 메모장이나 AI 답변의 복사 버튼으로 옮기는 게 안전해요.
대소문자 구분 | 코드는 영어 대문자와 소문자를 완전히 다른 글자로 봐요. Button과 button은 서로 다른 이름이에요. // 파일 이름도 마찬가지라 Cat.png와 cat.png를 헷갈리면 그림이 안 떠요. // 그래서 파일 이름은 처음부터 모두 소문자로 쓰는 습관이 좋아요.
생략된 코드 | AI가 답을 짧게 하려고 "// 나머지는 그대로"나 "..."처럼 일부를 줄여 쓴 거예요. // 이걸 그대로 붙여 넣으면 줄여 쓴 부분의 코드가 통째로 사라져서 앱이 망가져요. // 이런 표시가 보이면 "생략하지 말고 전체 코드로 다시 줘"라고 요청해요.

## 자주 만나는 문제
흰 화면 | 페이지를 열었는데 아무것도 없이 하얗기만 한 상태예요. // 대부분 코드 어딘가에 오류가 있어서 화면을 그리다 멈춘 거예요. // F12를 눌러 콘솔에 빨간 글자가 있는지 보고, 그 글을 통째로 복사해서 AI에게 주면 빨리 고칠 수 있어요.
에러 | 앱이 멈추거나 기능이 안 되게 만드는 문제예요. 콘솔에 빨간 글자로 떠요. // 신호등의 빨간불처럼 '여기서 멈췄어요'라는 뜻이라 꼭 고쳐야 해요. // 에러 메시지에는 무엇이, 몇 번째 줄에서 잘못됐는지 적혀 있어서, 통째로 복사해 AI에게 주면 돼요.
경고 | 앱은 돌아가지만 '이렇게 하면 더 좋아요'라고 알려 주는 문제예요. 콘솔에 노란 글자로 떠요. // 신호등의 노란불처럼 조심하라는 뜻이고, 당장 멈추지는 않아요. // 급한 에러부터 고치고, 경고는 나중에 한꺼번에 정리해도 괜찮아요.
한글 깨짐 | 한글이 ?, �, 이상한 기호로 바뀌어 보이는 거예요. // 컴퓨터가 글자를 저장하는 방식(인코딩)이 서로 안 맞아서 생겨요. // 파일을 UTF-8로 저장하고, HTML 맨 위에 <meta charset="UTF-8">이 있으면 대부분 해결돼요. AI에게 "한글이 깨져"라고 하면 넣어 줘요.
그림 깨짐 | 그림이 있어야 할 자리에 깨진 아이콘이나 빈칸만 보이는 거예요. // 대부분 파일 이름이나 위치(경로)가 코드에 적힌 것과 조금 달라서 그래요. 대소문자 하나만 달라도 못 찾아요. // 그림 파일 이름과 코드 속 이름을 나란히 놓고 한 글자씩 비교해 봐요.
반영 안 됨 | 분명히 고쳤는데 화면이 예전 그대로인 거예요. // 저장을 안 했거나, 브라우저가 예전 파일(캐시)을 보여 주고 있을 때가 많아요. // 저장 → Ctrl+Shift+R(강력 새로고침) → 시크릿 창으로 열기 순서로 확인하면 거의 해결돼요.

고치다 더 망가짐 | 하나를 고쳤더니 잘 되던 다른 곳이 망가지는 거예요. 아주 흔한 일이에요. // 코드는 서로 이어져 있어서, 한 곳을 바꾸면 다른 곳에 영향을 줄 수 있어요. // 잘 될 때마다 버전을 저장해 두면 "아까 그 버전으로 돌려 줘"라고 쉽게 되돌릴 수 있어요.
